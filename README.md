- Solve 5-7 problems

- Read solution + alternative approaches after
- Note patterns and edge cases

## 🎯 Interview Prep Tips

### Before solving:
1. **Read problem carefully** - edge cases matter
2. **Ask clarifying questions** (even if solo) - what's the input range? constraints?
3. **Think aloud** - explain approach before coding

### While coding:
4. **Write clean code** - variable names, comments
5. **Test with examples** - happy path + edge cases
6. **Check time complexity** - explain O(n) reasoning

### After solving:
7. **Optimize if needed** - can you do better than brute force?
8. **Review the solution** - did you miss a pattern?
9. **Note the pattern** - when will you use this technique again?

## ⚡ Common Blind 75 Patterns

| Pattern | Problems | Key Insight |
|---------|----------|-------------|
| **Two Pointers** | Two Sum, 3Sum, Merge Intervals | Converge from opposite ends |
| **Sliding Window** | Longest Substring, Min Window, Max Consecutive | Expand/contract window |
| **Binary Search** | Search Rotated, Find Peak | O(log n) solutions |
| **DFS/BFS** | Islands, Clone Graph, Tree traversal | Visit all reachable nodes |
| **DP** | Coin Change, House Robber, LIS | Memoize subproblems |
| **Union-Find** | Number of Islands, Connected Components | Group elements efficiently |

## 📌 Final Advice

✅ **DO:**
- Code it yourself first, no peeking
- Understand *why* solutions work
- Review multiple approaches
- Time your solutions
- Get 7+ hours sleep (brain consolidation)

❌ **DON'T:**
- Just watch solution videos
- Memorize without understanding
- Skip edge case testing
- Rush through - quality > quantity
- Panic if you get stuck (normal!)
